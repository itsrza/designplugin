## ۱) چیزهایی که باید از شما بگیریم (بلاکرها)

بدون این‌ها هر تغییری حدس و گمان است:

1. **برند و دامنه:** نام نهایی پروژه «میران» است یا «میرام»؟ دامنه/سایت مقصد چیست؟ لوگو و فایل برند دارید؟
2. **هویت بصری:** رنگ اصلی/دوم، فونت (وزیرمتن بماند؟ فونت اختصاصی دارید؟)، حالت تیره لازم است؟
3. **دامنه‌ی صفحات:** فقط فروشگاه؟ فروشگاه + محصول؟ وبلاگ/مقاله هم لازم است؟ صفحه‌ی جدیدی اضافه می‌شود (لندینگ، درباره ما، تماس)؟
4. **محیط فنی:** نسخه‌ی WordPress/PHP، قالب (WoodMart می‌ماند؟)، ووکامرس فعال است؟ صفحه‌ساز (Elementor)؟
5. **مهاجرت نام:** نام افزونه/پیشوندها/شورت‌کدها به `miran` تغییر کند یا برای سازگاری با صفحات موجود سرویا بماند؟ (پیشنهاد ما در بخش ۴)
6. **مرجع طراحی:** فایل فیگما/اسکرین‌شات/سایت الگو برای صفحه‌های هدف.

## ۲) تصمیم‌های معماری که پیشنهاد می‌کنیم (قابل تغییر)

| موضوع | پیشنهاد | دلیل |
|---|---|---|
| نام پوشه افزونه | `miran/` (تغییر `Plugin Name` و هدرها) | نصب تمیز، بدون تداخل با سرویا |
| پیشوند توابع | `miran_suite_*` با جست‌وجوی سراسری از `serviya_suite_` | جلوگیری از fatal در صورت فعال‌بودن هم‌زمان |
| شورت‌کدها | نگه‌داشتن `[serviya_*]` **و** افزودن نام‌های تازه `[miran_shop]` و… به‌عنوان alias | صفحه‌های موجود نمی‌شکنند، پروژه‌ی جدید نام خودش را دارد |
| تنظیمات | یک صفحه‌ی تنظیمات ساده (تلفن، واتس‌اپ، تلگرام، رنگ برند، عنوان) با `Settings API` | حذف شماره‌های hardcode، بدون نیاز به دست‌زدن به کد برای هر سایت |
| برندسازی CSS | تبدیل توکن‌های `--srv-*`, `--sp-*`, `--svp-*` به یک لایه‌ی مشترک `--mr-*` با `var()` و fallback | یک‌جا تغییر رنگ کل افزونه |
| i18n | پیچیدن متن‌های UI در `__()` با text-domain `miran` | آماده‌سازی برای چندزبانه (اختیاری، فاز ۴) |
| کیفیت | `npm run check` (lint PHP با php-parser + بررسی min) در CI، سپس PHPCS (WordPress-Extra) | جلوگیری از خطای سینتکس و min عقب‌افتاده |

## ۶) ریسک‌ها

1. **regex روی HTML ووکامرس** — با تغییر قالب می‌شکند؛ در فاز ۴ جایگزین شود.
2. **کش صفحه** — `data-ssr-state` ناهمگامی را تشخیص می‌دهد؛ بعد از استقرار کش را پاک کنید.
3. **تغییر نام پیشوندها** — اگر سایت هم‌زمان سرویا و میرن را فعال کند، پیشوندهای مستقل لازم است؛ جست‌وجوی سراسری برای `serviya` انجام و بازبینی شود.
4. **نسخه‌ها** — `MIRAN_VERSION`، هدر افزونه و `package.json` هم‌زمان به‌روز شوند.
