## نصب

1. پیشخوان وردپرس ← **افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه**
2. فایل `miran-<version>.zip` را انتخاب و **همین حالا نصب** کنید، سپس فعال.
3. اگر نسخه‌ی قبلی با نام دیگری نصب است، اول غیرفعال و حذف شود (افزونه تنظیمی در دیتابیس ذخیره نمی‌کند).

## ساخت نسخه‌ی جدید

```bash
# نسخه را در miran/miran.php (هدر + MIRAN_VERSION) و package.json به‌روز کنید
npm run check      # lint PHP + همگامی min ها
npm run package    # release/miran-<version>.zip
```
